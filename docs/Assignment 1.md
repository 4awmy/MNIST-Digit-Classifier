# Assignment 1
Training Models on the MNIST Dataset + Interactive Drawing App[cite: 1]

Team size: Maximum 5 students per team[cite: 1]

## Objective
Train three different models on the MNIST handwritten digits dataset, thoroughly experiment with hyperparameters, select the best-performing model with clear justification, save all three models, and build a simple interactive application that allows a user to draw a digit on a canvas and get a prediction from any of the three trained models.[cite: 1]

## Tasks

### 1. Data Preparation
• Load the MNIST dataset.[cite: 1]  
• Perform necessary preprocessing.[cite: 1]  
• Clearly document all preprocessing steps.[cite: 1]  

### 2. Train Three Models
You must train exactly three models:[cite: 1]

1. Classical Machine Learning model[cite: 1]  
Choose any suitable classical machine learning algorithm.[cite: 1]

2. Neural Network[cite: 1]  
A multi-layer perceptron. Fully connected layers only.[cite: 1]

3. Deep Learning Computer Vision model[cite: 1]  
A simple Convolutional Neural Network. Keep it basic similar to a standard introductory CNN architecture taught in lectures. Do not use very deep or pre-trained models.[cite: 1]

Important requirements for all models:[cite: 1]  
• Do not use default hyperparameters only. Systematically experiment with and tune key hyperparameters.[cite: 1]  
• Document the hyperparameter search process and final chosen values for each model.[cite: 1]  
• Evaluate each model using appropriate metrics.[cite: 1]  
• Compare the three models and choose the best suitable model. You will be asked to justify your choice based on performance, complexity, generalization, training time, and suitability for the digit recognition task.[cite: 1]  

### 3. Model Saving
• Save all three trained models so they can be loaded later by the application.[cite: 1]  
• Use a standard format appropriate for the framework you used.[cite: 1]  

### 4. Interactive Application
Build a simple web or desktop application that includes:[cite: 1]  
• A canvas where the user can draw a digit with the mouse or touch.[cite: 1]  
• A clear button to reset the canvas.[cite: 1]  
• A selection menu to choose which of the three saved models to use for prediction.[cite: 1]  
• A Predict button that feeds the drawn digit into the selected model and displays the predicted number.[cite: 2]  
• Clean, user-friendly interface. You may use any framework you like. You are allowed to use Al tools to help design and implement the UI.[cite: 2]  

The application should load the three saved models and be able to switch between them at runtime.[cite: 2]
